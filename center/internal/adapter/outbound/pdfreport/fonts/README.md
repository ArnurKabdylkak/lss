# Шрифты отчётов

`LiberationSans-Regular.ttf` и `LiberationSans-Bold.ttf` вшиты в
двоичный файл центра (`go:embed`) и нужны для PDF-отчётов: образ
собирается из `scratch`, системных шрифтов в нём нет, а отчёт должен
читаться кириллицей.

Лицензия — SIL Open Font License 1.1 (Liberation Fonts, Red Hat). Она
разрешает встраивание и распространение; при обновлении заменяйте оба
файла целиком.
