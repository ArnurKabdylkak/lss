# Панель оператора

Веб-панель объекта: наблюдение за платами и управление нагрузкой.
Проект — `ARCHITECTURE.md` §8 в `/data/mchs_software_tz`.

## Стек

React 19, Vite 6, Tailwind CSS 4, Chart.js 4. Взят из шаблона Mosaic,
лежащего рядом в `../tailwind-dashboard-template`.

JSX собирает встроенный в Vite esbuild: официальный плагин на Babel
тянет десятки пакетов, которые пришлось бы вносить в закрытый контур.

## Запуск

```bash
make install
```

```bash
make dev
```

В разработке Vite проксирует `/api`, `/healthz` и `/video` на
`localhost:8080` — там слушает центр. Порт задаётся переменной
`MCHS_CENTER_PORT`. В рабочей сборке панель отдаётся с того же адреса,
что и API, и прокси не нужен.

## Страницы

Маршрутизация по хешу, своя — ради трёх маршрутов зависимость в
закрытый контур не заносится (`src/lib/router.js`):

```
#/                  обзор комплекса: все комнаты разом
#/rooms/room-1      страница комнаты
#/devices           плоский список устройств, как было до комнат
```

Комнаты разведены по страницам намеренно: дежурный ведёт одну и не
должен отличать её поля от соседних. На обзоре — состояние,
температура, занятие, неисправности и камеры каждой комнаты; на
странице комнаты — управление подготовкой и состоянием, занятие,
назначения на тренажёры, её тренажёры и камеры.

Вкладка комнаты подсвечивается красным, если та в аварии, — даже
когда открыта другая страница.

## Комнаты

Объект показывается так, как устроен: комната, в ней велосипед,
лестница, силовая установка, тепловая пушка со своими уставками и
камеры этой комнаты. Раскладку панель берёт из `/api/v1/rooms` и
опрашивает раз в пять секунд; состав комнат задаётся на стороне центра
файлом `rooms.yaml`.

Тренажёр с полем `draft` подписывается «контракт в согласовании»:
лестница и силовая установка пока шлют данные не с платы, а с
имитатора, и дежурный должен это видеть.

Если раскладки нет, панель работает как раньше — плоским списком
устройств и отдельной сеткой камер.

## Камеры

Список камер и состояние трансляций панель берёт из `/api/v1/cameras`
и опрашивает его раз в пять секунд. Поле `playlist` непустое только у
камеры в эфире — его и открывает плеер; адресов камер с паролями
панель не видит.

Видео приходит в формате HLS. Safari играет его сам, остальным нужен
[hls.js](https://github.com/video-dev/hls.js) — он собран в бандл
(внешних ссылок в контуре нет) и грузится отдельным файлом только
тогда, когда камеру действительно показывают: плеер весит больше всей
остальной панели.

Камера без сигнала не прячется, а поднимается наверх сетки и
показывает причину словами — дежурному нужно знать, идти к камере,
звать сетевиков или проверять пароль.

## Оформление

Панель диспетчерская, а не витрина. Правила, из которых следует всё
остальное (токены — в `src/index.css`):

1. **Светлый фон.** Тренажёрный класс освещён; тёмная тема на свету
   бликует и теряет контраст, а инструктор смотрит на панель часами.
2. **Цвет — сигнал, а не украшение.** База серая; красный, жёлтый и
   зелёный означают ровно одно: авария, внимание, норма. Раскрашенный
   интерфейс перестаёт сигналить там, где это важно.
3. **Состояние не передаётся одним цветом.** Рядом всегда слово и форма
   значка: около восьми процентов мужчин не различают красный и зелёный.
4. **Крупные числа и подписи.** На показания смотрят от велосипеда,
   с двух-трёх метров.
5. **Никаких теней, градиентов и свечения.** Они не несут смысла и
   мылят края на светлом фоне.

Контраст всех пар «текст — фон» проверен по WCAG AA (минимум 4.5:1).

### Элементы

| Компонент | Зачем |
|---|---|
| `ui/Status` | состояние: значок, слово и цвет разом |
| `ui/Readout` | крупное показание с единицей |
| `ui/Readout` → `Bar` | линейная шкала с отметкой порога |
| `ui/Button` → `ConfirmButton` | подтверждение прямо в кнопке |
| `ui/Field` | поле с подсказкой, ошибкой и `aria-describedby` |
| `ui/Card` | плоскость с заголовком, без теней |

**Круговые шкалы заменены на число и полосу** намеренно: дугу читают
«на глаз», а инструктору нужно точное значение и видимая граница
порога — на полосе до неё видно расстояние.

**Опасные действия подтверждаются в самой кнопке**, а не в отдельном
окне: окно закрывает собой показания, а в диспетчерской нельзя терять
из виду то, чем управляешь. Подтверждаются сброс препятствия (оно
падает на трассу под человеком) и включение нагрева. Выключение
нагрева подтверждения не требует — остановить его безопасно всегда.

**Строка тревог** вверху страницы собирает перегрев, отказ датчика,
потерю связи с платой и обрыв потока. Она помечена `aria-live`,
поэтому программа чтения с экрана произносит её сразу.

## Закрытый контур

- **Ни одной внешней загрузки.** Шрифты системные, библиотеки в бандле,
  CDN не используются. Проверяется целью `make check-offline`.
- `npm install` внутри контура не отработает — зависимости вносятся
  вместе с проектом.
- **TLS обязателен** для видео: WebRTC в браузере требует защищённого
  контекста и по HTTP работает только на `localhost`.

## Что показывает

| Элемент | Источник |
|---|---|
| Индикаторы оборотов и температуры | `GET /api/v1/devices` |
| График «сейчас» | поток `GET /api/v1/stream` (SSE) |
| График «за час» | `GET /api/v1/devices/{id}/history` |
| Состояние реле и причина | последнее состояние устройства |
| Журнал команд | `GET /api/v1/commands` |
| Камеры | медиасервер напрямую, не через центр |

Опрос раз в 10 секунд оставлен подстраховкой на случай, если поток
оборвётся незаметно; основной источник обновлений — SSE.

## Управление

Кнопки подачи и снятия нагрузки, уставки защиты. Два правила, которые
видны в интерфейсе:

- **Подача — это разрешение, а не принуждение.** Плата отклонит её при
  перегреве или отказе датчика, и защита останется в силе. Отклонённая
  команда показывается как отклонённая, с причиной, — кнопка не остаётся
  в неопределённом состоянии.
- **Возврат должен быть ниже порога.** Без гистерезиса реле щёлкает на
  каждом измерении, поэтому панель не даёт отправить такие уставки.

Имя оператора уходит **в теле запроса**, а не заголовком: HTTP-заголовки
ограничены ISO-8859-1, и браузер отказывается отправлять запрос с
кириллицей в заголовке.
